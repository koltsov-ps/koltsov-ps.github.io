About

I've been shipping software since 2004 — desktop, web, high-load backends, and, for the last decade, iOS. These days I lead mobile development at Prequel; before that I built language-learning products at Skyeng, the Tinkoff Investments app, and document workflows at SKB Kontur.

Remembrall, a spaced-repetition flashcard app, is my own corner of the App Store: offline-first storage, CloudKit sync, file parsing, and enough theming code to repaint the whole app in two palettes. Outside of that, I keep a small set of Swift packages — Core Data helpers, structured logging, layout and sync utilities — that travel with me from project to project.
